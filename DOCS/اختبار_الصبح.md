# اختبار الصبح

شغل اللعبة من `07_TEST\SOL_LAB\launch_lab.ps1` فقط. ما رح تطلع شاشة موافقة ZombieBuddy.

اكتب كلشي بالعربي متل ما بتحكي، وخلي سول جنبك بالبيت بالبداية. إذا طلعت شاشة خطأ اكبس متابعة وصورها.

## 1. الزراعة (كل واحد لحال، استنى يخلص)

| اكتب | لازم يصير |
|---|---|
| `شو عنا بذور وعدة` | جدول بالبذور والأدوات بأسماء اللعبة ومكان كل شي |
| `زكاتك احصدي الحصاد` | بتمشي عالزرع وبتحصد |
| `زكاتك اسقي الزرع` | بتجيب المرش وبتسقي |
| `زكاتك عالجي الزرع` | بتعالج اللي عليه عفن |
| `زكاتك نظفي الزرع من العشب` | بتقلع العشب |
| `زكاتك حطي للزرع سماد` | بتسمّد |
| `احرثي الارض` | بتفلح أرض جديدة |
| `زكاتك ازرعي البذور اللي بهاد الموسم` | بتاخد بذور من المخزن وبتزرع |

انتبه: هل بتمشي للصندوق وبتاخد الغرض؟ هل بتعمل الحركة والزرعة بتتغير؟ هل بترجع الأداة وبتحط المحصول بالصندوق؟

## 2. الشغل لحالها

- `شوفي عنا بالمزرعة`، وبعدها `شو ناقصنا للزراعة`
- `اهتمي بالمزرعة`: اتركها شوي وراقب، وجرب `شو عم تعملي`
- `وقفي شغل المزرعة`: لازم توقف وترجع الأدوات
- `ضلي بالبيت ارتاحي`: لازم تمشي عالبيت وترتاح

## 3. الكلام فوق راسها

امشي معها شوي: لازم كل شي يكون عربي شامي، وما يطلع إنجليزي أبداً.

## 4. الصحوة والمجي

1. ابعد عنها لحد ما تصير النقطة **صفرا**.
2. `سول فايقة؟`: لازم تصير **خضرا** وتجاوب بدون ما تتحرك.
3. `تعالي مشي`: عد 5 دقايق، بيوقف مع Pause، وبعدها بتطلع خارج شاشتك وبتمشي لعندك.
4. `تعالي بالسيارة`:
   - إذا سيارتها قريبة منك ومحمّلة: بعد 3 دقايق بتطلع جنبها وبتجيك سواقة.
   - إذا سيارتها بعيدة: رح تقلك بصراحة إنها لسا ما بتقدر تجيبها، وهاد متوقع. نقل السيارة من بعيد لسا ما دخل، بدو تجربة على عالم منسوخ أول.

## 5. الباقي

- جدول المخزون الطويل: هل سلس؟
- الركوب: أول كرسي ركاب فاضي، وكرسي السواق بأمر السواقة بس.

ابعتلي شو زبط وشو ما زبط، وصورة لأي شي غريب.
