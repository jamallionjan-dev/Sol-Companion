# بطاقة دخول النموذج

هاي الورقة اللي بيستلمها أي نموذج بيتصل بعقل سول. بتنبني تلقائياً من أفعال العقل (`model_router.py`).

This is the sheet any model connected to Sol's Mind receives: who she is, its one job (pick one action as a JSON line), the action list with examples, and her memory. It is built at runtime by `05_TOOLS/sol_mind/model_router.py` (`sheet()`, from `COMMANDS`, `CARD_ACTIONS`, `EXAMPLES`, `EXTRA_EXAMPLE` and the rules text) and logged as "briefing sheet sent to the model, N chars".

## القاعدة / The rule

> جمال: "لاتنسة تحدث بطاقة العقل دايما مع العقل".
> كل تغيير بالعقل لازم يحدّث بطاقة العقل بنفس التغيير: البطاقة اللي بيبنيها `model_router.py` وهالملف.

Every Mind change updates the model card in the same change: the runtime card in `model_router.py` and this file. The gate `05_TOOLS/sol_kahlua/card_check.py <sol_mind dir>` refuses otherwise. `launch_lab.ps1` stops with exit 8 and `build_release.py` stops the release when it fails. It checks:

- every action the Mind can run from the model's answer is on the card with at least one example;
- nothing is on the card that the Mind cannot run;
- the card without her memory fits `model_router.CARD_BUDGET`, counted with the full game catalog (switch-gated actions such as `horn_hold` included) and with her hand on the horn;
- the section below matches the card built now;
- the offline route replay `test_s82_route_eval.py --as-is` passes.

Helicopter distinction: `sol_pilot_helicopter` transfers Sol to the pilot seat; GPS guidance and flight controls remain separate. The exact request **«سول فيكي تجيبي هليكوبتر»** dispatches `sol_summon_helicopter` and replies **«أكيد بقدر»** only after the Mind queues the action. The server then attempts to spawn a safe, registered helicopter of the last model the player drove (UH-1B Huey fallback), with a full JetFuel tank and key. The reply confirms queueing, not successful world spawn; the server result appears in `[SolHeliSpawn]` and the game log. Runtime behavior is not considered proven until checked in the isolated LAB.
