READ ME FIRST: Sol 0.28.3

1) Double-click "PLAY SOL.bat". It installs and enables the mod, starts Sol's mind hidden, and launches the game.
   (If you don't have ZombieBuddy, its Workshop page opens: subscribe, then double-click again.)
2) First time in game: ZombieBuddy asks you to approve Sol's Java file. Approve it.
3) In game open Sol settings, go to API key and pick Groq. Get a free key at https://console.groq.com/keys, paste it, press Apply key, pick a model, then Save and Test. The dot turns green.
   Or a model on your phone (iPhone or Android) instead of Groq: start the server in the phone app, phone and PC on the same Wi-Fi.
   In Sol settings pick "Phone / own server", type the address the app shows (192.168.1.20:11434 is enough) and the key, press Apply key, then Test.
   When it works it is saved by itself (address, key, model): nothing to type next time. If the phone's address changes, Sol finds it again.
   Easier: copy the address and the key (and the TLS pin if the app shows one) together on the PC and press Paste.
After that, every time you want to play: just double-click "PLAY SOL.bat".

Trouble: red dot? Run "FIX - اصلاح.bat". It runs the mind in a visible window so errors show; keep it open. Send a screenshot plus sol_launcher_log.txt, SolMind\sol_mind_service.log and SolMind\sol_mind_log.txt.
